# Home composition repair

The prior Home compressed its generated painting into a narrow strip and reduced Merlin to half size. This release displays the full painting with contain sizing, reserves space for the existing original-size animated companion, and places actual equipped items in a separate tray. Phone portrait uses an introduction above the dashboard; desktop and short landscape place it alongside. Short phones keep the original dock destinations in a horizontally scrolling row so neither controls nor the companion must shrink.

Your villages replaces the generic build-opportunity heading with actual named owned villages and individual building-status badges, retaining cost-checked build links. An isolated building completion is described as a building finished, never as an entire village complete. Completed notices still use the existing saved receipt/action; viewing Home does not spend or mutate care/inventory/notices. Future ready-to-open records can be represented, but the new on-site commissioning behavior is separate ongoing world work and is not claimed in this release.

Validation uses the real native browser game and a disposable save: ten layouts across normal/comic themes, the original Merlin care menu, per-village navigation, atomic shared equipment, independent mouse/touch scrolling, feeding, Training, Hospital, saved notices, camera framing/cancellation and explicit sound start/stop. Whole-composition screenshots are reviewed alongside overlap/full-art/original-companion-size assertions. This is responsive laptop-browser evidence, not a physical-phone hardware claim.

Existing art and Merlin sprites are unchanged. New Home CSS/script/core consuming pins match all three worker lists; the global build/cache advances. Publication follows the existing GitHub merge and guarded VPS updater with backup, runtime byte hashes, actual worker activation and cold offline checks. Ongoing canonical destination world, shelter/tutorial, commissioning, builder assistance and camera recognition work are not part of this visual subset.

Local result: all 27 native layout/interaction checks, four supplemental safe-area/navigation checks and 14 selected Python regressions passed. The normal/comic layouts cover 320×568, 390×844, 667×375, 844×390 and 1280×800; safe-area checks include portrait top/bottom insets and a short-landscape bottom inset. No physical-phone performance claim is made.
