# Hands-on Alderwing opening — v429

After landscape and the one-to-one Earth introduction, Merlin now teaches looking, forwards/backwards movement, sideways movement and the invert-vertical-look setting, in that order. The earlier desk input lock and the remaining anytime/Earth/shelter/chair/portrait/Home sequence are preserved. Completed introductions do not replay.

Practice receipts exist only for the current visible world step. Looking requires a newly started view drag, at least 36 accumulated pixels and 0.12 radians of applied camera change, followed by release. Cancelled/tiny/old gestures cannot complete it. Each movement direction requires 0.6 metres of actual travel with a deliberate stick or desktop WASD input. Collisions, old keys, held inputs crossing steps, auto flight, interiors and interrupted input cannot supply new receipts. Next remains disabled until both directions are complete. Each Next transition uses the existing durable phase save; a failure retains the current step for retry. Reload repeats an unfinished practice rather than certifying old input.

Settings contains an accessible 44px switch backed by `settings.invertVerticalLook`, default false, normalized to a boolean and written with the existing durable/cloud save path. Failed storage rolls back the switch and runtime value. Camera swipes, held look/aim and vertical arrow input read the current profile setting, including home and geographic camera routes. Horizontal look is unchanged. First-person world and home controls can open the existing Settings modal; input pauses and the singleton modal/focus is restored on close or host teardown.
