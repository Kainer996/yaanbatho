# Peep chatter

Sixteen original fictional human mumbles generated in ElevenLabs Sound Effects on 2026-09-05 for Burbz, using the user-authorized existing account. Four independent variants each of warm/rounded, bright, softly raspy and mellow voices. Prompts asked for invented syllables, one speaker, short natural human delivery and no recognizable dialogue, music, background sounds or existing game samples. No voice cloning was used.

Exported MP3 recordings are mastered to approximately -25 dB RMS with a -3 dB peak ceiling, gentle edge fades and mono 24 kHz / 64 kbps encoding. Runtime volume is 0.38 through the existing sound effects manager. Original exports and detailed provenance are kept in the local project checkpoint. All sixteen clips are different recordings; they are not pitch-shifted copies. No credentials or external audio service calls are part of the game.
