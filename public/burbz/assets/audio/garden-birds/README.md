# Garden birds

These are made sounds, not recordings. ElevenLabs Sound Effects v2 generated them from text prompts. No real bird was recorded.

The game mutes them while Merlin's wand listens. That way the sound ID never hears them, and never mistakes them for a real bird.

There are ten sounds: robin song, robin tick, blue tit song, great tit song, chaffinch song, goldfinch twitter, wren song, blackbird song, blackbird alarm and wing flutter. Most have three versions. Chaffinch song and wing flutter have two.

Every file is a mono MP3 at 44.1 kHz, levelled to about -20 dBFS. `manifest.json` lists each file with its prompt, source take, size and checksum.
