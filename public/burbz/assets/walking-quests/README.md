# Walking quest artwork · Burbz

Original assets generated with the built-in imagegen tool on 2026-09-07, using existing Merlin tutorial and village emblem references. Final prompts are in prompts.json. Warden required a background-only edit to remove the rendered checkerboard, preserving the character. Final files retain genuine alpha and are downsampled to at most 512px with Lanczos, WebP quality90. No existing artwork was overwritten.

- warden.webp: robin cartographer Warden Thistledown, 512×506.
- lantern-post.webp: Alderwing waylight, 341×512.
- wayfarer-rest.webp: fictional woodland shelter, 512×468.

Used in preview/journal, discovery dialog and checkpoint badges. Fictional story encounters, never claims of real people or buildings. Ordinary controls use SVG helpers.
