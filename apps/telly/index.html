Before you install

Built and tested on Omarchy Linux. Requires system Python 3.10+ with PySide6 (Qt 6), Node.js 18+, and X11 or XWayland with libX11. The browser installer also needs curl, ar (binutils), tar and xz. There is no Windows or macOS build.

Authenticated broadcaster playback is not yet verified. ITVX does not officially list Linux support. Accounts, location restrictions and playback remain controlled by each broadcaster.

Install and open

Extract the ZIP. Open a terminal in telly-source and run these commands as your normal desktop user, without sudo:

bash install.sh
bash "$HOME/.local/share/telly/launch.sh"

The installer adds Telly to your application menu. It uses installed Google Chrome if available; otherwise it downloads a private x86-64 Chrome runtime directly from Google.

Choose a channel and use Sign in on the cabinet. Sign in in the normal Chrome window, close it, then use the broadcaster’s Watch live control.

Your own television

Switch channels with the dial or presets. Drag the title area to move, and the edges to resize. Close × stays visible in fullscreen. Escape leaves fullscreen first, then closes the normal window.

Sign-ins and settings stay in your local Telly profile. The ZIP contains application source, with no browser profile or saved settings. See the README for browser updates and removal instructions.
