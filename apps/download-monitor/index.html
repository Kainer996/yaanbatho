Download Monitor

A native Linux dashboard for local download activity, with live progress where available and clear labels when the outcome is unknown.

Before you install

Requires system Python 3.10+, PyGObject, GTK 4 and libadwaita 1 on a graphical Linux desktop. On Arch/Omarchy the packages are python, python-gobject, gtk4 and libadwaita. There is no Windows or macOS build.

This is a local monitor. It cannot start, pause, resume or cancel downloads. A fresh install starts with no saved observations or queue.

Install and open

Extract the ZIP. Open a terminal in download-monitor-source and run these commands as your normal desktop user, without sudo:

bash install.sh
bash "$HOME/.local/share/download-monitor/launch.sh"

The installer checks the GTK dependencies and adds an application-menu entry. It does not change your top bar or window-manager settings.

What it can see

Supported Chromium-family download records, writable outputs of your curl, wget, wget2 and aria2c processes, and up to 500 files at the top level of Downloads. Browser history may lag; terminal tools often expose no reliable total or final outcome.

There is no dedicated Firefox, torrent, package-manager or remote-machine integration. Unavailable totals and uncertain states remain marked unknown. The Queue tab can display local dependency requests; it does not execute transfers.

Double-click a card to open its folder. Close or Escape exits without changing transfers. Data stays on your computer; the website receives none of it. See the README for full coverage and removal instructions.
