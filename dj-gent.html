▸Four personas, four lanes

Every tool is shaped by a persona — not a generic preset. The persona dictates the BPM range, the preferred Camelot keys, the energy arc, the do's and don'ts. Pick one when you call any tool, or set a default and forget it.

Warehouse Techno

122-134 BPM · 8A-1A

Long-form melodic and driving techno. Hypnotic, machine-led, builds slowly and rewards patience.

Peak Tech-House

126-132 BPM · 5A-8B

Drum-forward peak time. Vocal hooks, festival energy. Groove beats harmony in this lane.

Sunrise / Closing

118-124 BPM · 1A-4A

Closing slot, 5-7am. Emotional, slower, melodic. Reward the locked-in crowd with payoff.

Warm-up

115-124 BPM · 6A-9A

First two hours. Dance-floor architect. Set the room up for the headliner, don't steal the spotlight.

▸How it wires up

DJ-gent speaks MCP over stdio. No external services, no cookies, no APIs — the whole library ships in one JSON file you can edit. Register it with your MCP client:

{
  "mcpServers": {
    "dj-gent": {
      "command": "node",
      "args": ["/path/to/mcp-servers/dj-gent/dist/index.js"],
      "env": {
        "DJ_GENT_DEFAULT_PERSONA": "warehouse-techno"
      }
    }
  }
}

Then ask your agent: "I'm playing 8A at 124 bpm, energy 7. Pick the next track from this crate and tell me how to mix it" — it runs suggest_next_track with persona-aware ranking and hands you back the pick plus a build_transition plan.
